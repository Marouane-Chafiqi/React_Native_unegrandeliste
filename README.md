# MyRestaurant - Lab 6 (React Native / Expo)

Application mobile simple qui affiche le menu d'un restaurant avec `SectionList`.

## Fonctionnalités

- En-tête avec le titre My Restaurant
- Menu en sections : Appetizers, Main Dishes, Sides, Desserts
- Nom et prix de chaque plat sur une ligne
- Séparateur entre les plats
- Pied de page fixe en bas de l'écran

## Installation et lancement

```bash
git clone https://github.com/Marouane-Chafiqi/React_Native_MyRestaurant.git
cd React_Native_MyRestaurant/MyRestaurantApp
npm install
npx expo start
```

Scanner le QR code avec Expo Go.
